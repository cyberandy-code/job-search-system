# Analyze the search

## Read

Read the Applications tab in full and the `Job Search Profile`. Before analyzing, refresh outcomes: search Gmail for replies since the last update (rejections, recruiter outreach, scheduling) and update rows, flagging any uncertain matches.

## Measure

Report counts and rates, with the number of applications behind each (small samples are directional only; say so):
- Overall: applications, response rate (any reply), screen rate (reached Recruiter screen or beyond), interview rate.
- By lane, fit rating, seniority, channel, and whether there was a referral.
- By resume version where the Resume sent column allows it.
- Time from applying to first response, and how many are still silent after 30 days.

## Interpret

Lead with the two or three findings that should change what they do next week, for example:
- A lane or level that gets screens versus one that gets silence.
- Whether referrals change outcomes.
- Gaps that keep appearing in rejected Stretch roles.

Keep it honest. Do not claim a pattern from fewer than about five applications in a group. Separate what the data shows from your interpretation.

## Recommend

Propose specific changes, each one tied to a finding:
- Targeting changes for the scout (lanes, levels, filters, employers to add or drop).
- Resume rule changes for tailor-resume.
- Outreach changes (for example, referral-first for a lane).

Ask before editing the profile. When they agree, update the `Job Search Profile` so the scout and tailor-resume skills pick up the change on their next run.

Offer a chart where it helps (applications and screens by lane, or by month).
